# Full-screen control overlays — TEST20

The four normal-page cards provide the current labels/values to the focused overlay. This covers every existing page, including Dynamics, without a separate DSP parameter shadow. Range endpoints describe the displayed units (milliseconds, Hz, cents, semitones, percent or discrete values). Nonlinear controls show their displayed numeric position; encoder response itself is unchanged.

All 14 button bits are captured, including buttons with no assigned action. Combination labels wrap and compact for large masks. Existing navigation and simultaneous rising-edge routing are preserved. ENV opens the enlarged ADSR panel; combinations on cutoff-envelope pages focus the depth. Buttons with no action show the current panel without fake save/record confirmations. Knobs take focus while retaining held-button labels. PRESET shows bank name/index and current waveform. MASTER reads the unsquared pot position as percent, with startup suppression and a 16/4096 movement deadband. Endpoints trigger even below that threshold. SELECT/ALGO are drained and display the current panel, with no added navigation action.

State lives in the UI owner; audio rendering has no display calls. Unsigned time subtraction handles timer wrap. Held inputs prevent dismissal; every release or new input restarts the700ms grace. Redraw is capped at33ms; the same240x240 canvas is reused. Large Barlow numeric and title glyphs are stored in flash. Normal pages retain their prior information and CPU/XRUN meters. LED logic is unchanged.

Validation: every nonempty14-bit mask is checked in the state test, plus exact timeout boundary, timer wrap, latest-control precedence, held state, master jitter and endpoints. Host scripts render all14 individual buttons, combinations, K1..4, PRESET, MASTER, SELECT/ALGO, clamped controls, sustained holds, release grace and normal-page returns. Pixel checks verify full-screen transitions and jitter suppression; contact sheets are visually reviewed. A paired host audio test uses identical MIDI/sustain timelines with and without overlay-only events and compares all recorded PCM. Host timing does not substitute for real FM1 CPU/XRUN listening checks.

## TEST21 bootloader screen

The optional APP_UPDATE_STATUS callback is called from the existing platform hold timer with hold elapsed time, cancellation or final handoff. The app draws a dedicated countdown with priority over ordinary control overlays. Early release shows CANCELLED for700ms; a renewed hold restarts using the platform timer. The final screen is drawn synchronously after audio stops and before USB detaches. Host simulation explicitly models the same five-second threshold and reports simulated entry. The real device bootloader reset still belongs to the platform. The octave gesture restores its pre-first-button value when the pair is recognized. Native host captures cover five countdown digits, progress, cancellation before/after the old two-second message threshold, restart, long single-key holds, unchanged octave and final handoff.
